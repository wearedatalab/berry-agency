# Berry Concept Agency · demo de la home

Propuesta de diseño para la página de inicio de Berry Concept Agency, en español y en inglés.

- Español: <https://wearedatalab.github.io/berry-agency/>
- English: <https://wearedatalab.github.io/berry-agency/en/>

Es una demo: los textos y los datos están por validar, el formulario no envía y las páginas llevan `noindex` para que no salgan en buscadores.

Este repositorio solo tiene el sitio ya armado (HTML, CSS, JavaScript e imágenes). No se edita a mano: se vuelve a generar desde el proyecto de origen.

Hecha por DataLab.
